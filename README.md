# Airport_Management_System
Airport Management System is a full-stack web application built using MySQL, HTML, CSS, JavaScript, Node.js, Express.js. It manages flight and visitor records through a centralized dashboard with CRUD operations, search functionality, and real-time database connectivity using API-based communication.

# Key Features
- Manage flight and visitor records efficiently
- Perform Create, Read, Update, and Delete (CRUD) operations
- Real-time dashboard statistics and data updates
- Search and filter records quickly
- MySQL database integration with Node.js backend
- Responsive and user-friendly interface
- API-based communication between frontend and backend
